# 한국탐방 해설사

서울 문화유산 12곳을 **지도에서 눌러 가며** 익히고, 시험에서 필요한 해설을 **한국어와 영어로 나란히** 연습하는 청소년 문화유산해설사 준비 앱입니다.

청소년 문화유산해설사에 지원하는 **동생을 위해 만들었습니다.** 그래서 모든 경로의 출발지가 반포이고, 같은 동네에 사는 친구들에게 링크만 보내면 그대로 쓸 수 있습니다.

**▶ 앱 열기 — https://dyhan0528.github.io/koreahistory/**

설치 없이 브라우저에서 바로 쓸 수 있고, 홈 화면에 추가하면 앱 아이콘으로 실행됩니다. 오프라인에서도 열립니다.

---

## 왜 만들었나

### 1. 청소년이 반드시 알아야 할 역사라서

이 앱의 출발점은 기능이 아니라 내용입니다. 경복궁이 언제 세워졌는지, 창경궁이 왜 한때 '창경원'이었는지, 서대문형무소에서 무슨 일이 있었는지 — 이건 시험을 위해 외우는 지식이 아니라 한국에서 자라는 청소년이라면 알고 있어야 하는 역사입니다.

그런데 이 역사는 교실에서 글로 읽을 때와 그 자리에 서서 볼 때가 완전히 다릅니다. 창덕궁이 "자연 지형을 훼손하지 않고 건물을 배치했다"는 문장은 후원에 들어가 봐야 비로소 이해됩니다. 그래서 이 앱은 읽는 교재가 아니라 **답사를 전제로 한 앱**입니다. 답사지마다 "현장에서 눈으로 확인할 것"과 "그걸 보고 설명할 수 있어야 할 것"을 분리해 담았습니다.

외국인에게 우리 역사를 영어로 설명하는 일은 그 역사를 제대로 아는지 스스로 확인하는 가장 정직한 방법입니다. 그래서 언어 전환이 부가 기능이 아니라 앱의 축입니다.

### 2. 동생을 위해 만들었고, 출발지가 반포인 이유

이 앱에는 정해진 첫 사용자가 있습니다. 청소년 문화유산해설사에 지원하는 동생입니다. 기능 목록을 먼저 정하고 사용자를 찾은 앱이 아니라, 한 사람이 실제로 준비해야 하는 것에서 출발해 만든 앱입니다.

그래서 **출발지가 반포로 고정되어 있습니다.** 이건 아직 못 만든 기능이 아니라 설계 결정입니다. 12곳 전부에 "반포에서 여기까지 가는 길"이 지하철 노선과 출구 번호까지 적혀 있고, 가상의 사용자를 상정한 범용 경로 계산보다 실제로 그 집에서 출발하는 한 사람에게 훨씬 유용합니다. 답사지 목록도, 체크리스트도, 해설 포인트도 같은 기준으로 골랐습니다.

같은 전제를 공유하는 사람이 동생 하나만은 아닙니다. **반포에 사는 같은 과정 친구들에게는 링크만 보내면 그대로 쓸 수 있습니다.** 경로가 자기 집 기준으로 맞아떨어지기 때문입니다.

그래서 배포 형태도 링크 하나로 끝나게 했습니다. 카톡으로 문서 파일을 돌리면 누가 어느 버전을 보고 있는지 알 수 없고, 답사 현장에서 열어 보기도 불편합니다. 주소만 보내면 친구가 바로 지도를 열고, 12곳의 위치 관계를 한눈에 보고, 각 답사지의 구글·네이버 지도 버튼으로 실제 길을 확인합니다. 설치도, 로그인도, 파일 첨부도 없습니다.

다른 동네에서 출발하는 친구까지 넓히는 일은 필요해지면 하면 됩니다 ([로드맵](#로드맵)의 v1.1). 지금은 넓히지 않은 편이 더 정확합니다.

### 3. 한국의 색을 UX·UI에 적용하려고

한국 문화유산을 다루는 앱이 어느 나라 앱인지 알 수 없는 회색과 파란색으로 만들어져 있으면 앞뒤가 맞지 않습니다. 그래서 색을 장식이 아니라 **구조**로 썼습니다. 태극의 홍과 청, 오방색의 황과 녹을 가져와 각각에 역할을 하나씩만 줬습니다.

| 색 | 값 | 출처 | 이 앱에서의 역할 |
| --- | --- | --- | --- |
| 홍 | `#CD2E3A` | 태극 양(陽) | 주 액션, 선택된 답사지, 출발지 |
| 청 | `#0B4DA2` | 태극 음(陰) | 영어 텍스트 전용, 한강 |
| 황 | `#B07716` | 오방색 중앙 | '추정' 표시 전용 |
| 녹 | `#1F7A5A` | 오방색 동방 | 완료 표시 전용 |
| 백 | `#F3F4F6` | 오방색 서방 | 바탕 |
| 흑 | `#14161B` | 오방색 북방 | 본문 |

역할이 하나씩이라 색이 곧 정보가 됩니다. 지도에서 빨간 점은 아직 안 간 곳, 초록 점은 체크를 끝낸 곳입니다. 화면에서 파란 글씨는 전부 영어입니다. 노란 배지가 붙은 문장은 확인되지 않은 추정입니다. 설명을 읽지 않아도 구분됩니다.

앱 아이콘도 같은 원칙으로 태극을 국기 방향 그대로 렌더링했습니다 (홍은 위쪽, 머리가 왼쪽). 아이콘 PNG는 외부 라이브러리 없이 [`tools/gen-icons.js`](tools/gen-icons.js)에서 픽셀 단위로 생성합니다.

#### 4괘로 나눈 답사지 유형

태극기의 4괘를 답사지 분류에 썼습니다. 다만 괘를 장식으로 붙이지 않고, 뜻이 실제로 맞는 유형에만 배정했습니다. 괘 표식은 유니코드 문자가 아니라 세 획을 직접 그린 SVG이므로 어느 기기에서든 같게 보입니다.

| 괘 | 표식 | 유형 | 답사지 | 배정 근거 |
| --- | --- | --- | --- | --- |
| 건(乾) | 세 획 모두 이어짐 | 궁궐·왕실 | 경복궁, 창덕궁, 창경궁, 덕수궁, 운현궁 | 하늘·으뜸 — 왕실 |
| 리(離) | 이음·끊김·이음 | 박물관 | 국립민속, 국립중앙, 서울역사박물관 | 불·문화예술 |
| 감(坎) | 끊김·이음·끊김 | 근대사 현장 | 전쟁기념관, 서대문형무소역사관 | 물이자 험난(險) — 전쟁과 투옥 |
| 곤(坤) | 세 획 모두 끊김 | 서원·마을 | 성균관(문묘), 남산골한옥마을 | 땅·터전 |

원래 가이드에서 감(坎)은 사찰·석탑에 배정되어 있었지만, 이 12곳에는 사찰이 한 곳도 없습니다. 빈 분류를 두는 대신 감의 또 다른 뜻인 험난(險)을 따라 근대사 현장에 두었습니다.

#### 사진 대신 직접 그린 처마 단청

답사지 상세 화면 상단에는 궁궐 사진 대신 **막새기와 처마선과 단청 색동 띠를 SVG로 그려** 넣었습니다. 저작권이 확인된 궁궐 사진이 없고, 앱의 콘텐츠 보안 정책이 외부 이미지 호스트를 막기 때문입니다. 대신 이 띠의 색 구성이 답사지 유형을 나타내므로 장식이 아니라 표시로 작동합니다.

#### 그 밖의 전통 모티프

- **살창 구획선** — 구간 나누기를 회색 선 대신 격자창 패턴으로 처리했습니다.
- **단청 색동 게이지** — 진도 바가 채워질 때 홍·황·녹·청 색동 문양이 드러납니다.
- **낙관 스탬프** — 한 답사지의 체크를 다 채우면 '답사완료' 낙관이 찍히며 짧은 진동이 옵니다. 5음 음계로 만든 현악 소리는 기본 꺼짐이고 '내 진도'에서 켤 수 있습니다.
- **눌림 상태** — 버튼을 누르면 짙은 적색(`#A3222C`)과 함께 도장을 찍듯 살짝 축소됩니다.
- **모서리 반경** — 8px 이하로 제한했습니다. 과하게 둥근 모서리 대신 조선 목공예의 정갈한 선을 따랐습니다.

## 무엇을 할 수 있나

**지도** — 실제 위·경도로 배치한 서울 도심 개략도. 한강, 내사산, 한양도성 윤곽을 배경으로 12곳을 번호로 표시하고, 반포 출발점에서 선택한 답사지까지 점선으로 잇습니다. `전체 / 미방문 / 완료` 필터로 남은 곳만 볼 수 있고, 번호를 누르면 하단에서 미리보기 시트가 올라옵니다 — 지도를 벗어나지 않고 여러 곳을 비교한 뒤 상세로 들어갑니다.

**유형 필터** — 답사지 목록을 4괘 유형(궁궐·박물관·근대사·서원마을)으로 좁힐 수 있습니다.

**답사지 상세** — 한 화면 스크롤로 네 가지가 이어집니다.
- **답사에서 볼 것** — 현장에서 확인할 항목 3개. 눌러서 체크하면 지도의 점 색이 바뀝니다.
- **해설 포인트** — 시험에서 설명해야 할 내용. 한국어와 영어 전문이 함께 있습니다.
- **가는 길** — 반포(고속터미널) 기준 지하철 경로.
- **주변 식당** — 답사지별 4~5곳, 주소와 종류.

**언어 전환** — `한 / EN / 한·EN`. 세 번째 모드는 모든 문장을 KO·EN 두 줄로 붙여 보여 줍니다. 시험장에서 같은 내용을 두 언어로 대조하는 것이 이 앱의 핵심 용도입니다.

**해설 연습** — 해설 포인트 37개를 섞어 카드로 냅니다. 주제만 보고 스스로 설명한 뒤 펼치면 한·영 스크립트가 나옵니다. '외웠어요'로 표시한 개수가 진도에 쌓입니다. 특정 답사지만 골라 연습할 수도 있습니다.

**내 진도** — 체크 36개와 암기 37개를 합한 전체 진도 링, 유형별·답사지별 단청 게이지, 개발 히스토리, 완료 소리 켜기, 초기화.

**다크 모드** — 기기 설정을 따릅니다. 밝은 모드와 어두운 모드에서 색의 역할 체계를 따로 설계했습니다.

## 기술 구성

| 항목 | 선택 | 이유 |
| --- | --- | --- |
| 구조 | 단일 HTML 파일 + PWA | 빌드 도구 없음. 파일 하나 열면 그대로 동작한다 |
| 의존성 | **0개** | 프레임워크 없이 순수 JS. 12곳 앱에 React를 얹을 이유가 없다 |
| 지도 | 인라인 SVG (좌표 직접 투영) | 지도 API는 키·요금·오프라인 제약이 붙는다. 이 앱에 필요한 건 상대적 위치뿐이다 |
| 저장 | `localStorage` | 서버가 없으므로 계정도 없다. 학생이 바로 쓸 수 있다 |
| 서체 | Gothic A1 + Archivo | 한글 UI에 기하학적 산세리프, 숫자·영문에 좁은 그로테스크 |
| 오프라인 | 서비스워커 (앱 셸 프리캐시) | 답사지 지하에서 신호가 약해도 열려야 한다 |
| 배포 | GitHub Pages + Actions | push 한 번이 배포이자 개발 기록이 된다 |

파일 구조

```
index.html               앱 전체 (HTML + CSS + JS + 데이터)
manifest.webmanifest     PWA 매니페스트
sw.js                    서비스워커
icon.svg                 태극 아이콘 (벡터)
icons/                   PNG 아이콘 192·512·180·32
tools/gen-icons.js       PNG 아이콘 생성기 (node 내장 모듈만 사용)
.github/workflows/pages.yml   Pages 자동 배포
```

## 로컬에서 실행

`index.html`을 브라우저로 열면 앱은 바로 동작합니다. 단, 서비스워커와 매니페스트는 `file://`에서 작동하지 않으므로 설치·오프라인까지 확인하려면 로컬 서버가 필요합니다.

```bash
# node가 있으면
npx serve .

# python이 있으면
python -m http.server 8000
```

`http://localhost:8000` 접속 후 개발자도구 → Application → Manifest / Service Workers에서 확인합니다.

## 배포

`main` 브랜치에 push하면 GitHub Actions가 Pages로 올립니다. 최초 1회만 설정이 필요합니다.

1. 레포 **Settings → Pages → Build and deployment → Source**를 `GitHub Actions`로 변경
2. `git push origin main`

아이콘을 다시 만들려면:

```bash
node tools/gen-icons.js icons
```

## 로드맵

버전은 앱 안 '내 진도' 탭의 개발 히스토리와 릴리스 태그를 맞춰 갑니다.

- **v1.1 — 출발지 넓히기** · 반포가 아닌 동네에서 출발하는 친구가 생기면, 내 집 주소나 현재 위치를 출발지로 지정하고 12곳을 거리순으로 정렬. 지금은 필요하지 않아서 넣지 않았습니다.
- **v1.2 — 공유 링크** · 특정 답사지를 가리키는 링크(`?site=3`)로 친구에게 "여기 같이 가자"를 보냄.
- **v1.3 — 답사 기록** · 현장 사진과 메모를 답사지에 붙이기.
- **v2.0 — 진도 동기화** · 기기를 바꿔도 진도가 남고, 인솔 교사가 반 전체 진도를 봄. 서버가 필요한 첫 버전.
- **넣지 않은 가이드 항목** · 궁궐 실사 사진 히어로와 고지도 텍스처 베이스맵은 저작권이 확인된 이미지가 없어 SVG 작도로 대체했습니다. 태극 로딩 스피너는 이 앱에 네트워크 대기가 없어 넣지 않았습니다 — 없는 기다림을 만들지 않는 편이 맞습니다. 단청 AR 카메라 필터는 네이티브 권한이 필요하므로 스토어 배포 이후 과제입니다.
- **이후 — 스토어 배포** · Capacitor로 감싸 Google Play. 네이티브 기능(오프라인 지도, 위치 기반 자동 체크인)이 붙은 다음.

## 알려진 한계

- **진도는 기기에 저장됩니다.** 브라우저 저장소를 지우거나 기기를 바꾸면 초기화됩니다. 시크릿 창에서는 저장되지 않을 수 있습니다.
- **좌표는 개략값입니다.** 미터 단위 정확도가 아니며, 지도는 위치 관계 파악용입니다.
- **경로와 소요 시간은 추정입니다.** 실시간 교통 정보를 반영하지 않습니다.
- **출발지는 반포입니다.** 이건 한계가 아니라 [설계 전제](#2-동생을-위해-만들었고-출발지가-반포인-이유)입니다. 다른 동네에서 출발하는 사람은 각 답사지의 구글·네이버 지도 버튼으로 자기 경로를 확인하면 됩니다.
